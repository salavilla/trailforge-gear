# Trailforge

Landing page de una tienda de equipo para senderismo. Proyecto de demostración
usado para pruebas de corrección de bugs de UI a partir de una captura de pantalla.

## Cómo verlo localmente

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier
servidor estático:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
